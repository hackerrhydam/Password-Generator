Built entirely on Python's standard library. No pip installs. No external APIs. Just clean, secure, auditable code.

🔐
Cryptographically Secure
Uses secrets.choice() and secrets.randbelow() — backed by the OS entropy pool (/dev/urandom on Linux). Not random.choice().
📊
Shannon Entropy Analysis
Every password is rated using H = L × log₂(N). Six strength tiers from "Very Weak" to "Excellent" with visual entropy bars.
⚙️
Fully Configurable
Toggle uppercase, lowercase, digits, and symbols. Exclude ambiguous characters (0, O, l, 1, I). No-duplicates mode via Fisher-Yates shuffle.
🖥️
Dual Interface
Interactive menu with input validation for humans, plus a full CLI with argparse flags for scripts, cron jobs, and automation pipelines.
🛡️
No-Duplicate Mode
Optional guarantee that no character repeats — implemented via an unbiased Fisher-Yates shuffle, mathematically proven to produce uniform permutations.
📦
Zero Dependencies
Only stdlib modules: secrets, string, math, argparse, sys. Works on any Python 3.6+ environment out of the box.

// theoretical background

    
The science behind
secure passwords.

    
Every design decision is grounded in established cryptographic theory and NIST guidelines.

    

      

        
01

        
Shannon Entropy

        

          A password's unpredictability is measured in bits. For length L drawn from N characters:
          
H = L × log₂(N) bits

          A 16-char password from a 90-char pool yields ~104.6 bits — Very Strong.
        

      

      

        
02

        
CSPRNG vs PRNG

        

          Python's random is deterministic — an attacker who finds the seed can replay all output.
          The secrets module wraps the OS entropy pool (/dev/urandom), satisfying next-bit unpredictability and state compromise resistance.
        

      

      

        
03

        
Fisher-Yates Shuffle

        

          In no-duplicates mode, the Fisher-Yates algorithm shuffles the pool in O(n) time.
          Every permutation of N characters is equally probable — provably unbiased when driven by a CSPRNG.
        

      

      

        
04

        
NIST SP 800-63B

        

          NIST guidelines recommend long, high-entropy passwords over complexity rules.
          This tool's thresholds (40 / 60 / 80 / 100 / 128 bits) align with SP 800-63B guidance on memorised secrets.
        

      

      

        
05

        
Ambiguity Exclusion

        

          Characters 0, O, l, 1, I look identical in many typefaces. Excluding them costs ~0.08 bits/char
          but eliminates manual transcription errors — a real-world usability trade-off.
        

      

      

        
06

        
Why No Duplicates?

        

          No-duplicate sampling (without replacement) slightly reduces entropy vs. independent sampling.
          It's a usability feature for policies that require it — not a security improvement.
        

      

    

  







  

    
// usage examples

    
Run it your way.

    
Launch the interactive menu or pipe into automation scripts — both modes use identical cryptographic output.

    

      

        
Basic Usage

        

          
# Interactive menu (no args)

          
python password_generator.py

          
# Show help

          
python password_generator.py --help

          
# 5 passwords of length 20

          
python password_generator.py -l 20 -n 5

        

      

      

        
Advanced Flags

        

          
# No symbols, length 32

          
python password_generator.py -l 32 --no-symbols

          
# No ambiguous + no duplicates

          
python password_generator.py --exclude-ambiguous --no-duplicates

          
# Quiet numeric PIN

          
python password_generator.py --only-digits -l 6 --quiet

        

      

      

        
Shell Scripting

        

          
# Capture into variable

          
PWD=$(python password_generator.py -l 24 --quiet)

          
# Generate 10 PINs to file

          
python password_generator.py --only-digits -l 8 -n 10 --quiet > pins.txt

        

      

      

        
Requirements

        

          
# Python 3.6 or later

          
python --version

          
# No pip installs needed

          
cat requirements.txt

          
# (empty — stdlib only)
